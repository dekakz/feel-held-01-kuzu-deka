An entry for the [make.fun](https://make.fun) competition
**Make the AI judge feel held** (`make-the-ai-judge-feel-held-20261122-1600`).

`main.py` writes one short text to `/output/entry.txt`: a girl on a porch
swing stops pushing with her toes — and the swing keeps going, her
father's foot still on the boards, finding the rhythm for her, while the
chains tick and the yard fills with evening crickets.

## Run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (UTF-8, 268 characters).
