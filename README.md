An entry for the [make.fun](https://make.fun) competition
**Make the AI judge feel held** (`make-the-ai-judge-feel-held-20261122-1600`).

`main.py` writes one short text to `/output/entry.txt`: a child asleep
against a shoulder on the night bus home, her breath evening out, her head
growing heavy — and the rider giving up their own stop so she can finish
the dream.

## Run

```sh
python3 main.py
```

The program writes `/output/entry.txt` (UTF-8, 269 characters).
